# 🌿 Maya Reynolds Therapy — Homepage Clone & Redesign

A front-end assignment submitted for the Front-End Developer Internship at **Grow My Therapy**.

The task was to clone the homepage of [conejovalleycounseling.com](https://www.conejovalleycounseling.com/home), then redesign it end-to-end using a fictional therapist profile (Dr. Maya Reynolds, PsyD — Santa Monica, CA) as the source of truth for content, theme, and imagery.

## 🛠️ Tech Stack

- Next.js
- Tailwind CSS
- Deployed on Vercel

## ✅ What Was Done

**Part 1 — Clone**
Recreated the original homepage's layout, section order, spacing, and responsiveness as closely as possible, using Tailwind for styling and reusable design tokens (colors, spacing) instead of one-off values.

**Part 2 — Redesign**

- Replaced the original color palette with a new cream / sage green / deep green theme suited to a calm, editorial therapy brand.
- Rewrote all homepage copy (hero, about, specialties, FAQs, CTAs) based entirely on Dr. Maya Reynolds' profile — her focus on anxiety, trauma, and burnout, her work with high-achieving professionals, and her Santa Monica practice.
- Replaced every image with new ones that fit the new theme and support each section's message.
- Headings and copy were written with local SEO in mind (specialty + location keywords worked into the hero and section copy).

**Part 3 — New Section**
Added an "Our Office" section that doesn't exist in the original template, describing Maya's Santa Monica office (quiet, private, natural light) with supporting photos, styled consistently with the rest of the site.

**Part 4 — Video Walkthrough**
A 5-minute Loom walkthrough demoing the site as if presenting the first draft to Dr. Reynolds, covering desktop and mobile, explained in non-technical language.
